# 🏛️ HỆ THỐNG QUẢN LÝ SALE - MÔ HÌNH KIẾN TRÚC SONG ANH

Hệ thống Web App Quản lý Báo cáo Sales & Pipeline Đơn hàng dành riêng cho Đội ngũ Sales Mô hình Kiến trúc Song Anh.

---

## 👥 Ban Phụ Trách
- **Chỉ huy & Quản lý:** Phạm Hoàng Tiến
- **Cộng sự Sales:** Võ Minh Sang
- **Đại diện Ban Giám Đốc:** Mai Xuân Thiện
